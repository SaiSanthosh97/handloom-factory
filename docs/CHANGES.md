| 2026-11-23 | C-001 | **Serverless redesign.** The ASP.NET Core API, PostgreSQL, EF Core, Docker, Hangfire, JWT/refresh tokens and MediatR were removed. The app is now a .NET 10 MAUI Android app with a local encrypted SQLite database on each phone, synced through ntfy.sh with the owner's phone as the hub and a private encrypted channel per worker. Login is tap name + 4-digit PIN. Pay period is Sunday–Saturday, paid Saturday end of day. Rate per employee with history. English + Kannada. Only the admin edits past days. Offline-first. CSV export only (no backup/restore). Optional plain ntfy push notifications.
